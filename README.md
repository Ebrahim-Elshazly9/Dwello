# 🏠 Dwello — Find Your Dream Home

A modern and responsive real estate landing page built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**, based on a Figma UI design.

## 🎨 Design

The project is inspired by the following Figma design:

**Find Your Dream Home — Website UI Template**

[Figma Design](https://www.figma.com/design/pqXAKmMJpAmmDeJYvV48Tg/Find-Your-Dream-Home-Website-UI-Template--Community-?node-id=1-2&t=lf5v1ix8vFZjIveF-0)

## 🚀 Tech Stack

* **React** — Building reusable UI components
* **Vite** — Fast development and build tooling
* **Tailwind CSS** — Responsive styling and modern UI design
* **Framer Motion** — Smooth animations and interactive transitions
* **Lucide React** — Modern and consistent icons
* **JavaScript** — Application logic

## ✨ Features

* Responsive navigation bar
* Desktop mega menu
* Responsive mobile sidebar
* Account dropdown menu
* Search interface
* Hero section
* Popular properties section
* Why choose us section
* Testimonials section
* Help section
* Responsive footer
* Smooth animations with **Framer Motion**
* Interactive hover effects
* Fully responsive design using **Tailwind CSS**
* Reusable React components

## 🎯 Project Goal

The goal of this project is to recreate a modern real estate landing page from a Figma design while practicing modern frontend development techniques.

The project focuses on:

* Building reusable React components
* Creating responsive layouts with Tailwind CSS
* Implementing interactive UI components
* Adding smooth animations with Framer Motion
* Using Lucide React for modern icons
* Managing component state with React Hooks
* Converting a Figma design into a functional web interface
* Building responsive navigation for desktop and mobile

## 🎨 Styling

The project uses **Tailwind CSS** for the entire UI styling.

Tailwind CSS is used for:

* Responsive layouts
* Spacing
* Typography
* Colors
* Flexbox and Grid
* Hover states
* Transitions
* Responsive navigation
* Component styling

## 🎬 Animations

**Framer Motion** is used to create smooth and interactive animations throughout the application.

Examples include:

* Navigation animations
* Mega menu transitions
* Dropdown animations
* Hero section animations
* Hover interactions
* Mobile menu transitions
* Element entrance animations

## 📱 Responsive Design

The landing page is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

Tailwind CSS responsive utilities are used to adapt the layout and navigation across different screen sizes.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Ebrahim-Elshazly9/Dwello.git
```

Navigate to the project:

```bash
cd Dwello
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🛠️ Available Scripts

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
